# Buckedin Web 🚗💨

A modern, family-first, driver-rewarding rideshare and travel web platform built with **React**, **Vite**, and **Tailwind CSS**.

---

## 🎨 Design & Aesthetic Requirements

1. **Theme Palette: Blue & White**
   - High-contrast electric & royal blue accents (`#0e85ee`, `#0267ce`, `#0352a6`, `#bae0fd`, `#f0f7ff`).
   - Clean, modern white backdrop with subtle radial blue glows and soft frosted effects.

2. **Navigation Bar**
   - **Pill-shaped**: Floating rounded capsule navigation bar centered at the top of the viewport.
   - **Glassmorphic**: Built using backdrop blur (`backdrop-blur-xl`), translucent white glass styling (`bg-white/70` to `bg-white/80`), subtle white glass borders, and soft elevation shadows.
   - **Tabs**: **Home**, **Drivers**, **Families**, and **About** (with mobile responsive drawer support).

3. **Bottom Footer: Strictly Black**
   - Deep solid black background (`bg-black` / `bg-[#0a0a0a]`).
   - Dedicated **Contact Us** section with 24/7 hotline (`+1 800-BUCKEDIN`), support email (`support@buckedin.com`), and physical HQ address.
   - Dedicated **Terms & Conditions** and **Privacy Policy** links with fully interactive legal popups.
   - Newsletter signup, mobile app download links, and trust & safety certifications.

---

## 🚀 Key Features

- **Interactive Ride Request Widget**:
  - Live pickup and destination selectors with GPS location button.
  - Multi-tier ride options: *Buckedin Go*, *Buckedin Comfort*, *Family XL* (with free child car seats), and *Executive Black*.
  - Upfront fixed fare guarantee with instant booking modal simulation.
- **Live Travel Radar**:
  - Visualized city map trajectory with nearby simulated active drivers (Sarah, David, Elena) and arrival ETA.
- **Drivers Portal**:
  - 88% fare take-home breakdown vs. legacy rideshare apps.
  - Interactive Weekly & Monthly Earnings Calculator with city selection slider.
  - Quick 3-minute driver partner application form.
- **Families Portal**:
  - Guaranteed child seats: Infant capsules, Convertible toddler seats, and High-back booster seats.
  - Buckedin Guardian Mode™ phone telematics simulation, 4-digit boarding PIN, and pediatric CPR certified drivers.
- **About Section**:
  - Our founding story, mission, safety metrics (14.8M+ miles, 4.96 rating, <15s response), and interactive FAQ accordion.

## 💻 Quick Start

### 1. Development Server
To launch the Vite development server with hot-reload:
```bash
npm run dev
```

### 2. Production Build & Preview
```bash
npm run build
npm run preview
```
